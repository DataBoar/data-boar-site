Data Boar no Windows — demo em minutos, SEM Docker

Sem Docker, sem virtualização, sem complicação. Instala direto no Windows. O demo usa dados falsos (sintéticos) — nada seu sai do PC, zero risco. Roda até em máquina modesta ou Windows antigo. Feito para quem nunca usou "terminal" nem "Python" — cada passo diz o como e o porquê.

⚠️ A regra de ouro (leia antes de tudo). Você vai colar comandos no Terminal — a telinha onde aparece PS C:\Users\voce>. Não digite python e Enter antes: se aparecer >>>, você entrou no Python sem querer (isso dá erro maluco) — feche e reabra o Terminal.

Passo 0 — abra o PowerShell que já vem no Windows

Tecle Windows → digite PowerShell → Enter. Essa telinha já está no seu Windows, não precisa instalar nada. Apareceu PS C:\Users\voce>? É ele. Apareceu >>>? Abriu o Python por engano — feche (lembra a regra de ouro).

Passo 1 — instale o Terminal e o Python (2 comandos)

Cole um por vez no PowerShell:

winget install Microsoft.WindowsTerminal
winget install Python.Python.3.12

Por que winget e não a Microsoft Store? O winget já vem no Windows e pega a versão certa; a Store empurra sempre a mais nova (3.14), que costuma dar dor de cabeça. Por que a 3.12? A mais nova muitas vezes ainda não tem tudo pronto — a 3.12 é testada e funciona.

Agora feche o PowerShell e abra o Windows Terminal (Windows → Terminal → Enter) — ele copia-e-cola melhor, menos erro bobo. (Sem winget? Raro. Baixe o Python 3.12 em python.org/downloads/windows — não a 3.13/3.14 — e marque "Add python.exe to PATH".)

Passo 2 — instale o Data Boar

No Terminal (prompt PS C:\>, nunca o >>>), cole uma linha por vez:

python -m pip install --upgrade pip
python -m pip install --user pipx
python -m pipx ensurepath

🟡 Vão aparecer avisos amarelos (...is not on PATH, A new release of pip...) — é normal, não é erro. Só se preocupe com vermelho que tenha a palavra Error. Feche e reabra o Terminal mais uma vez. Depois:

pipx install data-boar

Passo 3 — rode o DEMO (comece sempre por aqui)

data-boar --demo

O Terminal mostra que está rodando (algo como servidor em 127.0.0.1:8088) — isso já confirma que funcionou no seu PC. Para ver o painel, abra o navegador (Edge, Chrome ou Firefox) e digite exatamente isto na barra de endereço:

http://127.0.0.1:8088

Sem asterisco, sem aspas. O painel (dashBOARd) abre com uma varredura de demonstração (CPF/e-mail de mentira, nada seu). Abriu em inglês? Troque no seletor de idioma no cantinho. Para parar: volte ao Terminal e aperte Ctrl + C.

✅ O --demo é o primeiro contato: dados sintéticos, roda só na sua máquina (loopback), zero risco. Serve para validar que roda e ganhar confiança — antes de tocar em qualquer dado real. Validado funcionando no Windows.

Passo 3.5 — rodar de verdade (nos seus dados) — com ajuda

O --demo é auto-suficiente. Para varrer os seus dados de verdade, o Data Boar precisa de um arquivo config.yaml que aponta para onde olhar (qual pasta ou banco). Ele não adivinha: você aponta o lugar. Esse é um próximo passo guiado — fale com a gente que ajudamos a montar o seu config.yaml. Com ele pronto:

data-boar --web --allow-insecure --config caminho\do\seu-config.yaml

O --allow-insecure é normal para rodar local (sua máquina, sem certificado) — não é inseguro no seu PC. Comece sempre pelo --demo.

Passo 4 — atalho com ícone (para nunca mais voltar ao terminal)

  1. Botão-direito na Área de Trabalho → Novo → Atalho.
  2. No caminho, cole: %USERPROFILE%\.local\bin\data-boar.exe --demo
  3. Nome: Data Boar → Concluir. Botão-direito → Propriedades → Alterar ícone → aponte para o ícone do javali (fornecemos o .ico).

Pronto: duplo-clique no javali abre o painel. Nunca mais precisa do terminal.

Qual Windows você tem? Este guia é para Windows 10 e 11. Windows 7 (bem antigo) é caso especial — nos chame, há outro caminho (ou o MSI, em construção). Travou? Manda uma foto da tela. Na maioria das máquinas roda direto — zero Docker, zero virtualização.

Data Boar on Windows — a demo in minutes, NO Docker

No Docker, no virtualization, no hassle. Install straight on Windows. The demo uses fake (synthetic) data — nothing of yours leaves the PC, zero risk. Runs even on a modest or older Windows machine. Built for people who have never used a "terminal" or "Python" — each step tells you the how and the why.

⚠️ The golden rule (read this first). You'll paste commands into the Terminal — the window showing PS C:\Users\you>. Do not type python and Enter first: if you see >>>, you accidentally entered Python (that causes weird errors) — close and reopen the Terminal.

Step 0 — open PowerShell (already in Windows)

Press Windows → type PowerShell → Enter. This window is already on your Windows, nothing to install. See PS C:\Users\you>? That's it. See >>>? You opened Python by mistake — close it (remember the golden rule).

Step 1 — install the Terminal and Python (2 commands)

Paste one at a time in PowerShell:

winget install Microsoft.WindowsTerminal
winget install Python.Python.3.12

Why winget and not the Microsoft Store? winget ships with Windows and picks the right version; the Store always pushes the newest (3.14), which often causes trouble. Why 3.12? The newest often isn't fully ready yet — 3.12 is tested and works.

Now close PowerShell and open Windows Terminal (Windows → Terminal → Enter) — it copy-pastes better, fewer silly errors. (No winget? Rare. Download Python 3.12 from python.org/downloads/windows — not 3.13/3.14 — and tick "Add python.exe to PATH".)

Step 2 — install Data Boar

In the Terminal (prompt PS C:\>, never >>>), paste one line at a time:

python -m pip install --upgrade pip
python -m pip install --user pipx
python -m pipx ensurepath

🟡 You'll see yellow warnings (...is not on PATH, A new release of pip...) — that's normal, not an error. Only worry about red lines with the word Error. Close and reopen the Terminal once more. Then:

pipx install data-boar

Step 3 — run the DEMO (always start here)

data-boar --demo

The Terminal shows it's running (something like server at 127.0.0.1:8088) — that already confirms it works on your PC. To see the panel, open your browser (Edge, Chrome or Firefox) and type exactly this in the address bar:

http://127.0.0.1:8088

No asterisks, no quotes. The panel (dashBOARd) opens with a demo scan (fake CPF/email, nothing of yours). Opened in Portuguese? Switch it in the language selector. To stop: go back to the Terminal and press Ctrl + C.

✅ --demo is the first contact: synthetic data, runs only on your machine (loopback), zero risk. It's there to prove it runs and build confidence — before touching any real data. Verified working on Windows.

Step 3.5 — running for real (on your data) — with help

--demo is self-contained. To scan your real data, Data Boar needs a config.yaml that points to where to look (which folder or database). It doesn't guess: you point the place. That's a guided next step — talk to us and we'll help build your config.yaml. Once ready:

data-boar --web --allow-insecure --config path\to\your-config.yaml

--allow-insecure is normal for running locally (your machine, no certificate) — not unsafe on your PC. Always start with --demo.

Step 4 — a desktop shortcut with an icon

  1. Right-click the Desktop → New → Shortcut.
  2. Paste the path: %USERPROFILE%\.local\bin\data-boar.exe --demo
  3. Name it Data Boar → Finish. Right-click → Properties → Change Icon → point to the boar icon (we provide the .ico).

Done: double-click the boar to open the panel. No terminal needed again.

Which Windows do you have? This guide is for Windows 10 and 11. Windows 7 (very old) is a special case — reach out, there's another path (or the MSI, in progress). Stuck? Send a screenshot. On most machines it runs directly — zero Docker, zero virtualization.
