DATA DISCOVERY · SEM TI

Como descobrir onde estão os dados pessoais da empresa

Resposta direta: além de perguntar às áreas, varra as pastas e arquivos onde o negócio realmente trabalha — PDF, Excel, Word, ZIP, exports de CRM/ERP. Uma ferramenta de data discovery LGPD local aponta padrões (CPF, e-mail, dados bancários etc.) e gera relatório. Não precisa ser de TI para o caminho Windows + demo; banco de dados pode vir depois.

Onde os dados costumam se esconder

  • Pastas de clientes e “Arquivo morto”
  • Planilhas e exports de sistemas
  • ZIP de backup e anexos salvos fora do e-mail
  • SharePoint / pastas de rede / nuvem sincronizada no PC

Passo a passo (sem jargão de servidor)

  1. Demo primeiro — data-boar --demo com dados de mentira. Guia: windows.html.
  2. Pasta de teste — copie poucos arquivos sintéticos ou uma pasta controlada; nunca comece pelo disco inteiro.
  3. Relatório — Excel com caminho e tipo de achado. Você abre o arquivo e confere.
  4. Decisão humana — restringir acesso, arquivar ou eliminar o que já passou do prazo é processo do escritório.
Local-first. A varredura roda no seu ambiente. O conteúdo dos documentos dos clientes não é o produto a ser enviado para a nuvem do fabricante — o que você leva é o relatório de achados.

Solução LGPD sem precisar de TI / sem Docker

Docker é opcional para quem já usa contêiner. Para escritório, PME e profissional liberal, o caminho nativo no Windows foi feito para quem nunca usou terminal. Microempresas muitas vezes não são obrigadas a nomear DPO — ainda assim precisam saber onde estão os dados. Ver FAQ.
