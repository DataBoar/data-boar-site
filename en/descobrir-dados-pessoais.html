DATA DISCOVERY · NO IT NEEDED

How to find out where your company’s personal data is

Direct answer: besides asking the departments, scan the folders and files where the business really works — PDF, Excel, Word, ZIP, CRM/ERP exports. A local LGPD data discovery tool flags patterns (CPF, e-mail, bank details, etc.) and produces a report. You do not need to be in IT for the Windows + demo path; databases can come later.

Windows without Docker — demo →   Understand the LGPD inventory

Where the data usually hides

  • Customer folders and the “dead archive”
  • Spreadsheets and system exports
  • Backup ZIPs and attachments saved outside e-mail
  • SharePoint / network folders / cloud synced on the PC

Step by step (no server jargon)

  1. Demo first — data-boar --demo with fake data. Guide: windows.html.
  2. Test folder — copy a few synthetic files or a controlled folder; never start with the whole disk.
  3. Report — Excel with path and finding type. You open the file and check.
  4. Human decision — restricting access, archiving or deleting what is already past its time limit is the office’s process.
Local-first. The scan runs in your environment. The content of your clients’ documents is not the product to be sent to the vendor’s cloud — what you take away is the findings report.

LGPD solution without needing IT / without Docker

Docker is optional for those who already use containers. For offices, SMBs and independent professionals, the native Windows path was built for people who have never used a terminal. Micro-businesses are often not required to appoint a DPO — they still need to know where the data is. See the FAQ.
